# Conceptual Internal Spaces in Large Language Models

This repository contains an open, exploratory research program on natural-language rule construction, Conceptual Internal Spaces (CIS), and cross-platform functional behavior in large language models.

The central research questions are:

- Can rules constructed solely through natural language function consistently across different LLM platforms?
- If platform-specific responses differ while fundamental rule-following functions remain similar, does this suggest the possibility of a platform-independent natural-language rule layer?

- `paper/02_conceptual_internal_space.md` — Operational definition and minimum criteria for CIS

## Research status

**Working Paper — Version 0.1**  
**Stage:** Exploratory / hypothesis-forming

This repository is intended to expose the research process as it develops. Preliminary observations, negative results, revisions, hypotheses, and reproducibility materials may be added before the research is considered complete.

Independent replication, criticism, falsification, and extension are welcome.

## Scope note

CIS is used here as an operational concept for functionally observable behavior associated with natural-language-defined boundaries. This repository does not claim that CIS is a physically distinct or neural space inside a model, nor that different LLM platforms necessarily implement the same underlying mechanism.
