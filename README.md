# Natural-Language Rule Construction Across LLM Environments

This repository contains an open, exploratory research program on natural-language rule construction, Conceptual Internal Spaces (CIS), and cross-platform functional convergence in large language model environments.

## Current research questions

- **RQ1:** Under what conditions can natural-language-constructed rules produce comparable rule-related functions across different LLM environments?
- **RQ2:** When platform-specific responses or structural realizations differ, which rule-related functions—such as boundary recognition, contextual separation, switching, persistence, or scope restoration—converge across environments, and where does that convergence fail?

## Research status

**Working Paper — Version 0.2**  
**Stage:** Exploratory / hypothesis-forming

The current evidence includes small recorded manual pilots and historical exploratory cross-platform observations. The project does not claim universal portability, a shared hidden mechanism, or superiority of explicit CIS-style framing over ordinary rule presentation.

The aim is to identify the systems, conditions, and rule-related functions for which cross-platform functional convergence can or cannot be reproduced.

## Scope note

CIS is used here as an operational framework for functionally observable behavior associated with natural-language-defined contextual boundaries. It is not a claim that a physically distinct, neural, or uniquely implemented internal space has been discovered inside an LLM.

This repository is intended to expose the research process as it develops. Preliminary observations, negative results, revisions, hypotheses, limitations, and reproducibility materials are retained so that independent replication, criticism, falsification, and extension remain possible.
