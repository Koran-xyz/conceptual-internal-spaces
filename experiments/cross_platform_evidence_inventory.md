# Cross-Platform Evidence Inventory

**Status:** Working research record  
**Purpose:** Separate recorded pilot evidence from historical exploratory observations before standardized cross-platform replication.

This inventory does **not** treat every prior observation as equally strong evidence. Recorded pilot trials are separated from earlier exploratory construction work for which exact prompts, raw outputs, model/version details, or independent repetitions have not yet been normalized.

## Evidence-status rules

### Recorded pilot evidence
Use this label when the project currently retains a sufficiently explicit experimental description, expected response, observed response, and repetition record to reconstruct the reported result.

### Historical exploratory observation
Use this label when a phenomenon was observed during earlier research construction but has not yet been converted into a standardized experimental record with exact prompt, environment metadata, raw output, and independent repetition.

### Replicated cross-platform evidence
This label should be reserved for future tests using a common or semantically matched protocol across distinct AI environments with documented raw records and predefined evaluation criteria.

## Current gap

The present paper therefore has **recorded within-platform pilot evidence** and **cross-platform exploratory provenance**, but not yet a fully standardized cross-platform benchmark. This distinction should remain explicit in the paper until new controlled replications are completed.

## Next data-collection template

For each future cross-platform trial, record at minimum:

- platform/product;
- publicly visible model/version, if available;
- test date;
- fresh or continuing conversation;
- exact rule specification;
- tested function;
- expected behavior or scoring criterion;
- raw user/model exchange;
- repetition number;
- result status: observed / replicated / failed / ambiguous;
- known confounds or missing metadata.
